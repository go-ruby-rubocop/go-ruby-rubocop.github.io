go-ruby-rubocop is a pure-Go (no cgo) reimplementation of the core of Ruby's RuboCop linter — the offense/cop framework (a Cop interface, an Offense model, a Registry and a Runner/commissioner), a faithful core cop set of 22 cops across Layout / Style / Lint / Metrics, the .rubocop.yml configuration model (ParseConfig) and the default formatters. Built on the go-ruby-parser Ruby AST and lexer, it inspects a Ruby source string — its lines, its token stream and its AST — and emits offenses whose cop name, location and message byte-match the rubocop gem, without any Ruby runtime. It is the RuboCop backend for go-embedded-ruby, bound by rbgo as a native module just like go-ruby-regexp and go-ruby-erb — differential-tested against the gem, 100% coverage, CI green across 6 arches and 3 OSes.

A faithful port of RuboCop's linter core in pure Go, cgo disabled, so it cross-compiles and embeds anywhere. Detecting an offense from a source string — its cop name, its line/column, its message — is deterministic and needs no interpreter, so it lives here over the go-ruby-parser AST and lexer. Each cop computes a source-range Correction; the host applies the edit. Detection, location and message text are validated differentially against the rubocop gem, compared byte-for-byte. It is a standalone, reusable module and the RuboCop backend for the sibling org github.com/go-embedded-ruby.
